# Triage Labels

| Rôle canonique    | Label GitHub      | Signification                             |
| ----------------- | ----------------- | ----------------------------------------- |
| `needs-triage`    | `needs-triage`    | Le mainteneur doit évaluer le ticket      |
| `needs-info`      | `needs-info`      | Informations complémentaires nécessaires  |
| `ready-for-agent` | `ready-for-agent` | Prêt pour une implémentation par un agent |
| `ready-for-human` | `ready-for-human` | Intervention humaine nécessaire           |
| `wontfix`         | `wontfix`         | Le ticket ne sera pas traité              |

Quand un skill mentionne un rôle canonique, utiliser le label GitHub correspondant.
